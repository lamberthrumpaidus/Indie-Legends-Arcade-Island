# Indie Legends Arcade Island

**Satu pulau, banyak petualangan.**

</div>

**Indie Legends Arcade Island** adalah koleksi permainan arcade gratis yang dapat dinikmati langsung melalui browser. Menghadirkan 23 permainan dengan beragam pengalaman, mulai dari aksi, balapan, teka-teki, permainan klasik, hingga petualangan di dunia fantasi.

Di antara permainan yang tersedia, **SHINRIN — Spirit Forest** mengajak pemain menjelajahi hutan bernuansa Jepang, melewati gerbang dan jembatan, serta mengumpulkan roh dalam sebuah petualangan tiga dimensi. Permainan lainnya menawarkan tantangan singkat dan menyenangkan, seperti **Snake**, **Space Defender**, **2048**, dan berbagai permainan arcade lainnya.

Dirancang untuk dimainkan melalui **ponsel maupun laptop**, Indie Legends Arcade Island menghadirkan pengalaman bermain yang sederhana, responsif, dan bebas iklan. Setiap permainan memiliki karakter, suasana, dan tantangannya sendiri.
